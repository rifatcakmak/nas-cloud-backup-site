NAS Cloud Backup

NAS Cloud Backup is an owner-operated, noncommercial workflow for backing up personal files from a private network-attached storage device to the owner's Google Drive account.

Restic encrypts backups before Rclone transfers them to Google Drive. This website provides information only; it does not collect photos, files, or account credentials.

Only the owner uses the backup application. There is no public user registration or hosted photo gallery.
